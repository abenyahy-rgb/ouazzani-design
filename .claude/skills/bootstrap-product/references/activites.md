# bootstrap-product — activités outillées

> Généré depuis `core/method.yaml`. Chargé à la demande, jamais d'office.

## Activité 0 — Socle technique automatique

**Entrée.** Run autorisé ; dépôt identifié ; aucune arborescence /product non sauvegardée ; NOM DU PRODUIT recueilli auprès d'un humain ; connecteur d'espace de travail et emplacement de la racine fournis — chacun absent produit BLOCKED, jamais deviné ni dérivé du nom du dépôt.

**Tâche.** Calculer, sans question : arborescence, conventions, registre des chemins, Run Ledger et espace de travail se déduisent du registre ; l'existant, s'il y en a un, se lit dans le dépôt. Les questions que seul un humain tranche — autorités de gate, rôles — sont consignées en réserves, jamais posées ici.

**Vérification.** Bootstrap idempotent rejoué à vide : aucun artefact écrasé. Deux sources par contrainte de l'existant. Aucune question posée à l'humain.

**Sortie.** /product et /runs initialisés ; artifact-schema.yaml validé ; unknowns listés ; espace de travail instancié selon le plan calculé — « apf notion plan » en donne le compte — et sa carte enregistrée dans SOC-01.

Responsible : `factory-lead` · Accountable : `Product Owner` · Cadence C1, étape C1.1
